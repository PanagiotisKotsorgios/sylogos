ΕΛΕΥΘΕΡΟΙ ΠΟΛΙΟΡΚΗΜΕΝΟΙ — PREMIUM STATIC WEBSITE

Έκδοση με:
- Responsive HTML/CSS/JS
- Entrance / scroll reveal animations σε όλες τις βασικές ενότητες και στοιχεία
- Reduced-motion accessibility
- Φωτογραφικά backgrounds στα hero sections
- Gallery lightbox
- Scroll progress indicator
- Back-to-top button
- Νέα & Ανακοινώσεις placeholder
- Video / οπτικοακουστικό αρχείο placeholder
- Όλο το αρχικό φωτογραφικό υλικό μέσα στο assets/

Δεν απαιτείται Node, PHP, database ή build step.
Άνοιξε το index.html ή ανέβασε ολόκληρο τον φάκελο σε οποιοδήποτε hosting.
